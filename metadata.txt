about=One window with three modes on the same page: snap check, field naming, and move. Snap check tests target layers against reference layers within a tolerance, with a standard test plus optional special checks. Field naming writes values from reference features by a spatial rule and a multi-match policy, onto the source layer or into a temporary layer. Move previews a whole-feature translation and writes back only after you confirm. The window opens at 700 by 650 every time QGIS starts. A resize is kept only until QGIS exits and is not stored on disk. UI in English, 中文, Español, Français, العربية, Italiano, Deutsch, 日本語, and 한국어. Names in the language menu stay in each language. The first open follows the QGIS interface language; if that language is not one of the nine, or the locale cannot be read, English is used. A choice is remembered for this plugin. Arabic changes text only and does not flip the layout. Local files only; QGIS 3.28 through 4.99 (Qt 5 and Qt 6).
